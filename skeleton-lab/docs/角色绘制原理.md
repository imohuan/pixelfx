# 像素角色是怎么画出来的 —— 骨骼绑定、绘制方式、光影规则

> 本文基于 skeleton-lab 的骨骼核心（rig.js / rig-big.js）写成，供用 AI 实现自己的像素角色时参考。
> 所有结论都对应源码里的真实实现，标注了出处。

---

## 一、骨骼绑定：不是"绑"，是"算"

### 1.1 核心思想：正解 + 反解混合

这个角色**没有传统意义上的骨骼绑定**（没有权重、没有蒙皮、没有动画师手 K 的关键帧曲线）。它的思路是：

> **只声明骨架的尺寸和 4 个端点目标，中间所有关节用 IK（反向动力学）现场解出来。**

- **正解部分**（骨架形状）：骨盆 → 腰 → 胸 → 脖子 → 头，这条主干由几个标量驱动（crouch 蹲、lean 弯腰、yaw 转身），一层层往上叠。
- **反解部分**（四肢）：姿势只说"手要放到 (fx, fy)、脚要踩在 (ffx, ffy)"，IK 解出手肘、膝盖在哪里。

对应代码：`solve(pose)`（rig.js 第 71 行起）。

### 1.2 骨架的三个数据来源

**来源 1：尺寸表 `M`**（rig.js 第 37 行）——骨架的"DNA"

```js
const M = {
  pelvis: 19.7,   // 骨盆离地高度（决定腿挂在哪里）
  spine1: 2.8,    // 腰椎长度
  spine2: 4.6,    // 胸椎长度
  shoulderUp: 2.5, shoulderOut: 5.9,  // 肩窝相对胸口的偏移
  neckUp: 4.0, headUp: 3.1,           // 脖子、头顶
  hipDown: 1.1, hipOut: 2.8,          // 胯窝相对骨盆的偏移
  thigh: 8.6, shin: 8.3,              // 大腿、小腿
  upper: 7.6, fore: 7.4,              // 大臂、小臂
};
```

**骨头长度全部固定**。想让角色 200px 高？把这张表乘以 5（rig-big.js 的做法，`K` 倍数），其他逻辑一行不改。

**来源 2：姿势对象 `pose`**——每帧的输入

```js
pose = {
  fx, fy,        // 近手目标（y 负数=向上）
  bx, by,        // 远手目标
  ffx, ffy,      // 近脚目标
  fbx, fby,      // 远脚目标
  crouch, lean,  // 蹲、弯腰
  yaw, turn,     // 全身转、胸转（弧度）
  x, y,          // 身体平移（y 是腾空高度）
}
```

姿势**只描述端点和身体姿态**，不描述任何中间关节。肘和膝是解出来的。

**来源 3：极向量（pole vector）**——告诉 IK "关节往哪边弯"

两段骨头（如大腿+小腿）连到目标点时，膝关节位置在数学上有两个解（往前弯 or 往后弯），极向量就是那个"选择器"：
- 膝盖极向量固定朝前偏外（`kneePole`）→ 膝盖永远往前弯，像人
- 肘部极向量按手的高度动态变化：手放低时肘朝下后方，手举过头时肘朝外前方（`pole()` 函数，rig.js 第 106 行）
- 拿武器时还有一轮 16 次的圆周搜索，找"小臂最能贴合武器握把方向"的肘位

### 1.3 求解顺序（重要）

`solve(pose)` 内部按这个顺序解，每一步依赖前一步：

```
1. 胸部转角 turn     —— 不直接读姿势，而是从手的位移推算：
                       手往前伸 → 胸跟着转过去；手往后拉 → 胸打开
                       （fwd = (fx - STAND.fx) / 24，rig.js 第 78 行）
2. 脚 + 骨盆         —— 先假设骨盆在标准高度，检查两条腿能不能够到脚：
                       够不着 → 骨盆自动下沉（骨头不拉伸原则）
3. 腰 → 胸 → 脖 → 头 —— 主干正解，由 crouch/lean/yaw 驱动
                       头部"部分跟随"身体转动（35% 系数），所以转身时脸不丢失
4. 肩 → 肘 → 手      —— 两臂 IK，肩窝先"朝目标探出一点"（最多 1.8px）
5. 所有骨骼坐标系帧   —— 每根骨头记录 { 位置 t, 朝向矩阵 R }
```

**关键规则：骨头长度永不变化。** 手够不着就挪身体（骨盆下沉、肩膀前探），绝不拉长手臂。这让角色永远符合解剖直觉。页面上的"够不着"警告（shortfall 函数）就是这个原则的量化检查。

### 1.4 如果你用 AI 实现骨骼

给 AI 的提示词应该包含：

1. **骨架定义**：一张尺寸表（骨盆高、各段骨头长度）+ 骨架拓扑（ pelvis→spine→chest→neck→head，四肢挂点）
2. **姿势格式**：只允许端点目标 + 身体参数，禁止直接指定肘/膝
3. **两个数学函数**：
   - 两段 IK：`ik(根位置, 目标, L1, L2, 极向量)`——余弦定理求中间关节（rig.js 第 45 行可以直接抄）
   - 极向量投影：把"希望弯的方向"投影到垂直于骨头的平面上
4. **三条物理约束**：骨头不拉伸、骨盆会为脚下沉、胸部转向跟随手

## 二、绘制方式：不是分开画，是"3D 体积 → 深度缓冲 → 像素化"

### 2.1 整体管线

```
solve(pose) 解出骨架
      ↓
drawBody(S)：把每根骨头画成 3D 体积（球/胶囊/椭球）
      ↓ 写入一个 Z 缓冲区（每个像素记 z 值）
finish(S)：读缓冲区 → 上色 + 接缝 + 轮廓
      ↓
输出像素列表 { xs, ys, color, ink }  →  谁都能画到任何画布上
```

**这是整个系统最反直觉、也最强大的地方：它不是 2D 精灵图，是实时渲染的 3D 小人。**

### 2.2 每个部位怎么画（drawBody，rig.js 第 150 行起）

部位不是"分开画再拼"，而是**全部写进同一个 3D 深度缓冲**，谁在前谁后由 z 值当场决定：

| 部位 | 3D 形状 | 尺寸示例（1x） |
|---|---|---|
| 骨盆 | 椭球 | 半径 [2.9, 2.6, 4.2] |
| 腰腹 | 胶囊（骨盆→胸扫掠） | 半径 3 → 3.3 |
| 胸 | 椭球 | 半径 [3.4, 4.2, 5.5] |
| 脖子 | 胶囊 | 半径 1.25 → 1.15 |
| 头 | 两个椭球（颅+脸） | 颅 [3, 3.3, 2.8]，脸偏前 |
| 四肢 | 胶囊链 + 关节球 | 大腿 3.2→2.2，小臂 1.6→1.2 |
| 武器 | 沿手部坐标系逐点画 | 写进同一个缓冲 |

胶囊 = 一串逐渐变粗变细的球（`sweep` 函数）。**每个部位的"近端粗、远端细"就是这个扫掠半径**。

远侧的胳膊和腿画的时候标记 `curDim = 1`（变暗标志），上色时整体降一档——这是"远肢变暗"规则的来源。

### 2.3 深度缓冲决定遮挡

`plot(i, z, ...)`（rig.js 第 120 行）是唯一的写像素入口：

```js
if (Part[i] === 0) touched.push(i);    // 第一次画上去
else if (z <= Zb[i]) return;           // 已经有更近的像素盖着 → 丢弃
Zb[i] = z;                             // 记录我的深度
Part[i] = part;                        // 我属于哪个部位（画接缝用）
```

**所以不需要关心绘制顺序**——胸部后画也不会盖住前伸的手，因为 z 值说了算。手在胸前的 0.5px 也会正确遮挡。

### 2.4 关键设计：`src` 反向映射（每帧像素知道"我从哪来"）

`finish()` 输出的每个像素带一个 `src` 字段：**这个像素来自站立姿势的哪个像素**。实现方式是把当前像素坐标变换回骨架局部坐标，再映射到标准站姿的图上（`srcFor` 函数）。

用途：冰冻、中毒、描边等特效画在站立身体上后，能跟随骨骼运动跑到任何姿势的正确位置。这是"骨骼绑定"思想的另一种体现——**像素级绑定**，比传统骨骼权重更细。

### 2.5 姿势缓存

同一姿势只渲染一次（`CACHE` + `keyOf` 序列化姿势字段）。拖动滑块时每次微调都是新 key，命中率依然很高。你实现时也应该缓存：像素化 3D 场景不便宜（1x 站姿 421px，5x 9152px，12x 51092px）。

## 三、光影效果：从 3D 法线到 4 档色阶

这是角色"看起来专业"的全部秘密。规则数量不多，但每条都有明确的代码对应。

### 3.1 光源方向：全场景只有一个光

```js
const LIGHT = unit([-0.55, 0.72, 0.5]);
```

一个**归一化的 3D 向量**：x=-0.55（光从左前方来）、y=0.72（从上方来）、z=0.5（从观众侧来）。
**所有部位共享这个光**，所以受光面永远一致——这是"专业感"的第一来源。

### 3.2 每个像素的亮度 = 法线 · 光方向

画每个球/椭球时，逐像素算表面法线 n，亮度 `tone = dot(n, LIGHT)`：

```
dot = 1.0 → 正对光源 → 最亮
dot = 0.5 → 侧光     → 中间调
dot = 0.0 → 背光     → 暗部
```

这就是最基础的 Lambert 漫反射。**注意：这是渲染时的逐像素计算，不是美术手绘的明暗**——所以任何姿势下光影都自动正确。

### 3.3 四档色阶（不是渐变！）

`toneOf()` 把连续亮度压成 4 档：

```js
v > 0.8  → 档 0（亮）
v > 0.42 → 档 1（中间）
v > 0.08 → 档 2（暗）
其他     → 档 3（最深）
远侧肢体整体再降一档
```

然后查调色板：

```js
SHELL = [最亮 A, B, C, 最暗 D]   // 身体表面（皮、衣服）
CORE  = [E, F, G, G]            // 关节内部、腰腹等"核心"材质
```

**硬色阶是像素艺术的灵魂**。连续渐变会立刻让画面变成"矢量画"。每档之间是硬切换，最多用 1px 过渡。

### 3.4 抗噪：孤立像素吃邻居的多数票

压成 4 档后会出现"一个亮像素 surrounded by 暗"的噪点。`finish()` 里有一轮投票（rig.js 第 391 行）：某个像素的色调如果和同一部位的所有邻居都不同，就改成邻居中占多数的色调。这一步让色块边界干净、色带连贯。

### 3.5 接缝与墨线：两个部位相遇时的两种处理

`finish()` 扫描所有相邻像素对（rig.js 第 403 行）：

```
两个像素属于不同部位时：
  深度差 dz > 2.2px 或其中一个是金属 → 画 INK（墨线，最深的颜色）
  否则（两个部位贴着）              → 画 SEAM（柔和的缝线色）
取深度更远的那一侧画线（线画在"被挡住"的物体轮廓上）
```

**这就是为什么角色既有立体感又有清晰剪影**：手臂横在身前 → 手臂轮廓出墨线；大腿贴着骨盆 → 只有淡淡的缝。

### 3.6 外轮廓：整圈墨线

所有身体像素的外圈（上下左右四个方向检查，碰到空像素就记录）统一填 INK 色。**1px 的外轮廓是像素角色可读性的底线**——没有它，角色在复杂背景上会糊掉。

### 3.7 复刻清单：你自己实现时的规则

按重要性排序：

1. **一个光源，全场景统一**。定义成 3D 向量，别用"左上角"这种 2D 说法
2. **亮度 = 法线点乘光方向**。如果你不做真 3D，至少给每个部位一个"受光面朝向"手工分配
3. **4 档色阶，硬切换**。调色板从亮到暗排好，禁止连续渐变
4. **远侧肢体降一档**。近手 4 档全用，远手最多用到第 3 档
5. **部位相接处画线**：深度差大 → 墨线；贴着 → 缝线
6. **外轮廓 1px 墨线**，颜色比最暗的暗部更深
7. **孤立像素修正**（投票），色块才会干净
8. **每帧缓存渲染结果**，姿势没变不重画

### 3.8 一个可以直接给 AI 的光影提示词

```
你正在画一个像素角色（约 190px 高）。规则：
1. 光源在左前上方，全画面统一。
2. 每个身体部位用 4 档色阶：高光 / 亮面 / 暗面 / 最暗，硬色阶无渐变。
3. 身体远侧（左手左腿）整体比近侧暗一档。
4. 不同部位相接：前面的部位轮廓处画 1px 深色墨线；贴合的部位用浅缝线。
5. 整个角色外轮廓 1px 墨线（比最暗色更深）。
6. 高光只出现在：头顶、肩膀上缘、大腿上侧、手臂上侧这些"朝上的面"。
7. 暗部颜色带一点冷色偏移，亮部带一点暖色偏移。
```

## 四、把三部分串起来：一帧的完整流程

```
输入 pose（4 个端点 + 姿态参数）
  ↓ solve()：解出 20 个关节的 3D 位置
  ↓ drawBody()：每个关节间画 3D 体积，逐像素算法线、写深度缓冲
  ↓ finish()：4 档色阶上色 → 接缝/墨线 → 外轮廓 → 输出像素列表
  ↓ 页面/引擎把像素列表画到画布上（乘以显示缩放）
```

配合头发等附属物理（hair.js 的 verlet 链），挂在骨架暴露的关节点上即可，不需要进骨骼系统。
