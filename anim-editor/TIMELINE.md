# 时间轴规则

这份文档说明 anim-editor 底部时间轴的排布与拖拽规则。改时间轴相关代码前先读一遍，
尤其是「一、名词」和「五、注意事项」，那里的每条都是踩过坑之后定下来的。

---

## 一、名词

| 名词 | 含义 | 数据 |
| --- | --- | --- |
| 图层 | 左侧图层面板里的一项，也是时间轴左侧轨道头那一项 | project.tracks[] 里的一条 |
| 行 | 图层内部的一条横带。一个图层可以有多行 | 片段上的 clip.row（从 0 开始） |
| 片段 | 时间轴上的一段标签（角色 / 特效 / 靶子 / 叠加态） | project.clips[] 里的一条 |
| 参考框 | 拖拽时显示的虚线框，表示“松手后会落在哪” | 由 dragPreviewRow 驱动，不写进数据 |
| 临时行 | 拖拽需要时才出现的一行，不再需要时自动消失 | 只是 row 序号，不是新图层 |

**关键区分**：图层 ≠ 行。一个图层里可以有好几行。**临时行只加行，绝不新建图层。**

---

## 二、唯一一条硬性约束

> **同一个图层的同一行里，任何两段时间都不能重叠。**

这条约束无条件成立：拖拽中、松手时、载入工程时，都要满足。

- 判断重叠：a.t < bEnd 且 aEnd > b.t（两端各留 1e-6 容差）
- 时间范围：clip.t 到 clipEndOf(clip)

---

## 三、两种拖拽场景

### 场景 1：跨图层拖拽（片段要换图层）

判定：鼠标所在图层 ≠ 片段原图层。

- 片段**留在原图层原行**，位置不跟着鼠标走（只有时间 x 跟着变）
- 在目标图层画**参考框**，位置是**实际落位行**，不是鼠标所在行
- 落位行查找：从鼠标所在行**向下**逐行找第一个放得下的；全部行都满 → 临时新行
  （轨道会临时变高把这一行显示出来，否则参考框会被裁掉）
- 松手：片段搬进参考框那一行

**参考框只在这个场景出现。** 它的含义只有一个：目标位置在哪。

### 场景 2：同图层内拖动 / 拉长度

判定：鼠标仍在同一个图层里（横向拖动、拖两端改时长都算）。

- **不显示参考框**
- 片段自己跟着手走，行号实时由空位决定：从最上面一行开始找第一个放得下的行
- 压到同行别的片段 → 自动沉到下面第一个空行（没有就新建临时行）
- 拖回来不再重叠 → 自动合并回上面那一行，空出来的临时行随之消失
  （表现：图层高度从 2 行变回 1 行）

这就是“向右拖被挤下去、再拖回左边自己回来”的行为。

### 两种场景同时触发

跨图层拖拽时，片段其实还在原图层里，时间却在变。所以场景 1 的流程里也要
先做一次场景 2 的沉行检查（resizeSink），否则片段会压到原图层的邻居。

## 四、落位算法（伪代码）

```js
// 1. 这一行能不能放下
rowFree(trackId, row, t, dur, excludeId)
  -> 同图层、同一 row、id 不是自己、时间不重叠

// 2. 从 hintRow 往下找第一个空行
findDropRow(trackId, hintRow, t, dur, excludeId)
  for r from hintRow to 最大行:
      if rowFree(r) return { row: r, temp: false }
  return { row: 最大行 + 1, temp: true }   // 全满 -> 临时新行

// 3. 松手兜底
if (!rowFree(当前行)) 往下找空行   // 任何情况下都不许重叠
```

## 五、注意事项（都是踩过的坑）

1. **拖拽开始时要冻结轨道几何**（snapshotLanes / laneHitAtFrozen）。
   目标图层长出临时行会让下面的轨道整体下移，鼠标原地不动也会“换轨道”，
   表现是参考框忽然消失、片段莫名回到原处。

2. **落位计算绝不能看见预览行**。渲染用 rowCountView（含预览行），
   计算用 rowCount（只看真实片段）。混用会让算出的行落在轨道可视范围之外，
   参考框被裁掉，看起来就是“没有参考框”。

3. **临时行不是图层**。不要往 project.tracks 里插条目，
   也不要回到旧的“自动装箱（packing）”思路——那是按时间自动重排行，
   会让片段在没有重叠的情况下自己跳行。

4. **载入工程后要规范化行号**（normalizeRows）。
   工程 JSON 里可能本来就有重叠（早期默认数据里“靶子”和“叠加态”就重叠了），
   载入时要按同一约束自动分层，否则一打开就是错的。

5. **松手处理里不要引用已删除的变量**。之前 up() 引用了一个已删除的
   tempTrack，抛异常导致监听器没清理，鼠标松开后一直处于拖拽状态。

6. **参考框只属于场景 1**。同图层内出现参考框是错的——
   那里应该由片段自己直接移动。

7. **合并是自动的**：不需要“删除临时行”的专门逻辑。
   行数由片段的最大 row 推出来，片段回到上行后，多出来的行自然消失。

8. **向下找，不向上找**。落位永远从鼠标行（或最上面一行）往下找，
   不要跳过已被占用的行。

9. **吸附**：默认吸附到帧，按住 Alt 关闭；缩放用 Ctrl + 滚轮，以鼠标位置为锚点。
